# A per-function archive of candidate sources

**Why.** Each attempt's best C is kept, but candidates are not deduplicated or organized by what differs (AlphaEvolve's program database, MicroRCT's MAP-Elites cells).

**Do.** An archive per function: deduplicated candidate sources keyed by mismatch class and percent, for search and for later sessions.

**Done when.** The archive exists for near-miss rows; search seeds from it.

**Effort / value.** M / med. Evidence and sources: docs/research/notes-ideas-tooling-reproducibility.md #9.
