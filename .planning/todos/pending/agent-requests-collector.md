# Collect agents' tooling requests from their notes

**Why.** About 350 notes.md files hold requests for tools or information; nobody reads them in bulk.

**Do.** A `reverseapoc requests` command that extracts and groups request lines from attempt notes, with counts, as input for tooling todos.

**Done when.** The command lists grouped requests with counts and example paths.

**Effort / value.** S / med. Evidence and sources: docs/research/notes-ideas-agentic-projects.md #9.
