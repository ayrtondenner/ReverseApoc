<objective>
The region board (999.7): split each function's byte difference into 0x100-byte regions in check's JSON, and at 256 B
and up print a board naming, per region, the saved check of this attempt that is exact there or closest.

Purpose: a 256 B+ function differs in several places at once; the board tells the session which region is done and
which saved draft already solved a region, so it stops trading one region's fix for another's regression. 07.2-03's
observed note records the region summary (D-02), so this plan lands before 03 (RULINGS waves).
Output: `bytes.regions` in check JSON, `attempt.region_summary`, `attempt.region_board`, and the board in
`attempt check`'s output.
</objective>
