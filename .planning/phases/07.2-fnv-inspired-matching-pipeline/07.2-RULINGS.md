### The five pinned-form tests (D-26)

`hooks.ATTEMPT_FORMS` stays the five Phase 6 forms, shared by both session kinds, so readability sessions get no new
form (D-26). The new verbs live in `hooks.MATCHING_FORMS`, which only a matching session may run:

- 02 sets `MATCHING_FORMS = ATTEMPT_FORMS + (("giveup",),)`; 03 makes it `ATTEMPT_FORMS + (("giveup",), ("plan",))`.
- `hooks.forms_for(kind)` returns `MATCHING_FORMS` for `"matching"` and `ATTEMPT_FORMS` for `"readability"`.
  `attempt_form_matches(argv, forms=ATTEMPT_FORMS)` and `bash_allowed(command, kind="matching")` take the kind's
  forms; `attempt.form_allowed(argv, kind)` does the same, so a readability session's `attempt giveup` exits 2.
- `tests/test_hooks.py:585` keeps its `ATTEMPT_FORMS` assertion and gains an explicit `MATCHING_FORMS` tuple.
- `tests/test_attempt_wrapper.py:1399` and `:1625` keep `ATTEMPT_FORMS == PHASE6_FORMS` and gain an explicit
  `MATCHING_FORMS_07_2` tuple (`:1399`) and a readability refusal of every matching-only form (`:1625`).
- `tests/test_skill.py:120` compares against an explicit `SKILL_FORMS` tuple (the five) plus an explicit
  `PENDING_SKILL_FORMS` tuple (`(("giveup",),)` after 02, `(("giveup",), ("plan",))` after 03), and asserts
  `set(SKILL_FORMS) | set(PENDING_SKILL_FORMS) == set(hooks.MATCHING_FORMS)`. 09 empties `PENDING_SKILL_FORMS` and
  makes `SKILL_FORMS` equal `MATCHING_FORMS`.
- `tests/test_skill_readability.py:136` compares against an explicit `READABILITY_SKILL_FORMS` tuple (the five) and
  asserts that no matching-only form is quoted.

## Interface contracts (names fixed across plans)

### Schema 3 (07.2-01 owns all of it)
- `SCHEMA_V3 = 3`; `RECORD_FIELDS_V3` holds every kind; the driver writes every new record as schema 3.
- New attempt keys: `effort` (null: the CLI default; nights pass none, D-17), `harness` (one of `HARNESSES =
  ("claude", "codex", "agy")`), `backend` (the arm's provider: `"anthropic"` for the Claude login, else the
  backends.toml entry's `backend` value; pattern `[a-z][a-z0-9-]{0,31}`), `duration_ms` (int, or null with no result
  event), `cost_source` (one of `COST_SOURCES = ("cli", "estimate")`), `giveup` (null or the give-up object),
  `hold_run` (bool).
- The hold state is the record key `hold_run`, never `held` (D-26: `held` already means the signed asm hold in
  `picker.TierQueue.held`, `driver.tier_held` and the dry run's `held:` line). Console text says "hold run".
- `HOLD_EXACT = "HOLD_EXACT"`: a matching outcome valid only on schema 3 with `hold_run` true, for a hold-run attempt
  whose last plain check exited 0 (D-26). A `hold_run` record is never MATCHED.
- The give-up object: `{"category", "tried", "still_differs", "suspected_cause", "best_code"}`; `category` one of
  `GIVEUP_CATEGORIES = ("flags", "block_layout", "stack_layout", "register_allocation", "instruction_idiom",
  "types_or_struct", "call_convention", "compile_error", "other")` (D-04); `best_code` the best check's source path
  (`checks/NNNN.c`) or null.
- `KIND_LANDING = "landing"` (schema 3 only): `kind, schema, run, date, exe, unit, start, function, from_run,
  from_attempt, model, backend, harness, outcome, reason, gate, commit`. `outcome` is MATCHED or REFUSED; a MATCHED
  landing names its commit and no reason; a REFUSED one names its reason and no commit. A landing carries no tokens and
  no cost, so cost is never counted twice (D-26).
- The run totals of schema 3 count sessions over the schema-3 outcomes, `HOLD_EXACT` included.

### Harness (06, 12, 13, 15, 16)
- `DriveOptions` gains `night_model`, `picks`, `stratify`, `write_picks`, `hold` (06), `land_held` (06),
  `allow_egress` (12), `arms` (16).
- The hold-run marker is the file `build/driver/<run>/HELD` (D-17's name), constant `HOLD_RUN_MARKER = "HELD"`.
- The picks file: one function per line, `<exe> 0x<8 hex digits>` (`ufo2p 0x0008A0E0`), `#` starts a comment, blank
  lines ignored.
- `STRATA = ((0, 64), (64, 256), (256, None))`: `--stratify A,B,C` takes A rows under 64 B, B rows of 64 to 255 B and C
  rows of 256 B and up (the stats buckets' last two merged; the 256 B todo's six rows).
- backends.toml (12): `[arms.<name>]` tables. The Claude arms are keyed by their model id. Fields: `harness`,
  `backend`, `model`, `base_url` (absent for the Claude login and Codex/agy), `key_env` (absent likewise),
  `sends_disassembly`, `accepted_init` (list of init model strings), `prices` (`input`, `output`, `cache_read`,
  `cache_creation`, USD per MTok), `coauthor` (absent for Claude arms), `max_workers`. 16 adds `max_sessions`.
- `tools/reverseapoc/backends.py` (12): `Arm` dataclass, `load_arms(path) -> dict[str, Arm]`, `ArmError`,
  `session_env(arm, base_env) -> dict[str, str]`, `preflight(arm, env, *, allow_egress) -> None`.
- A non-Claude harness (codex, agy) runs only after its canary passed: the canary writes
  `build/driver/canary/<arm>.json` (`{"arm", "harness", "cli_version", "date", "result": "PASS"}`), and the driver
  refuses that arm when the file is absent, not PASS, or names another CLI version (D-13, D-21).
- The wrapper hash ledger (13): the driver sets `REVERSEAPOC_WRAPPER_LEDGER` for codex and agy sessions to
  `build/driver/<run>/ledger/<exe>__<function>__attempt-<n>.jsonl`, outside the session's workspace; the wrapper
  appends `{"path", "sha256"}` for every file it writes; the audit compares (D-26).
- Multi-arm (16): `--arm NAME=WORKERS`; each arm runs under run id `<run>-<NAME>`.

## Executor constraints (every plan)

- Worktree executors on Opus 5.5: never push, no network, no subagents, never install the unlazy Stop hook.
- NEVER type a bare `python`, `python3`, `python -` or an empty heredoc (it hangs this shell); run `uv run python

  may write under build/ at run time.

  never run docker in a worktree.

  (`tests/fakeclaude.py` pattern). Real canaries are the owner's and orchestrator's step after the phase.

- Never name the owner's private project.
- Per plan: host suite `uv run pytest -q && uv run ruff check .` in the worktree; the container suite
  (`docker compose run --rm test`) runs on the main checkout after the merge, never at the same time as the host suite.
