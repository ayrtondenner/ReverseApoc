<objective>
Multi-arm drive (D-22): one drive process running several model families in parallel, each arm with its own run id,
pick queue, usage pause and limits, over the same frozen pick list.

Purpose: spike 012's ten arms should not take ten sequential nights; running them side by side in one process keeps the
one lock, one audit and one commit queue the driver's safety depends on, where separate processes would trip each
other's lock, git index and audit.
Output: `--arm`, the coordinator's per-arm state, per-arm pauses and caps, records and stats by arm, and the runbook.
</objective>
