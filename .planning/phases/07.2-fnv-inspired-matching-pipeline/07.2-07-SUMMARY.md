# Phase 07.2 Plan 07: Name provenance markers (RL07) Summary

**readlint RL07 requires `/* src: TAG 0xADDR (confidence: ...) */` on every name a readability pass gives a `func_`, `D_`, `param_` or `local_` placeholder, judged on the diff (view at launch for `attempt check`, HEAD at landing), rejects malformed markers everywhere, is proven comment-only by a real Watcom compile, and is taught by the watcom-readability skill.**

## Decisions Made

See `key-decisions` in the frontmatter. The main one is per-scope pairing. The plan's literal rule ("a name new in the text where some base placeholder vanished") would also flag a `#define` added to name a literal, and any new name in another function. So RL07 judges each scope (the file, or one definition) on its own, and skips macro, typedef, tag, member and prototype-parameter names. `test_rl07_a_new_macro_is_no_rename` and `test_rl07_a_rename_is_judged_per_function` pin this.
