# Phase 07.2 Plan 12: Hosted Anthropic-compatible backends Summary

**A backends.toml arm table and one env builder for spike 012: `--night-model ARM` plus `--allow-egress ARM` runs DeepSeek V4.1-Flash, GLM-5.3, Muse Spark Open or hosted Qwen in the Claude Code harness with the arm's key as the bearer token. Every unsafe variant is refused before the first command, hosted records carry estimated costs and vendor credit, egress sessions cannot reach orig/ or third_party/, and the local llama.cpp arm runs on loopback with one worker.**

## Accomplishments

- **config/driver/backends.toml.** It holds the four Claude arms (keyed by their model id, no endpoint or key), `deepseek-flash`, `glm-5.3`, `muse-spark-open`, `qwen-hosted` and `qwen-local`. It holds variable NAMES only. Ids, prices and co-author addresses that could not be confirmed offline are marked "confirm at setup" in the file. Every hosted arm prices both cache classes as input, so an estimate can overstate but never understate.
- **backends.py.** `load_arms` validates each arm's exact field set and types. `harness` must be in `HARNESSES` (now defined once: `driver.HARNESSES` is the same object) and `backend` must match the schema-3 pattern. `key_env` must be an UPPER_SNAKE name, and a bad value is never echoed. `base_url` must be https, or http to loopback. A base URL without `key_env` must be loopback.
- **session_env.** It strips every arm's key variable, `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, the three default-model pins and `REVERSEAPOC_EGRESS` from every session. A hosted arm then gets its endpoint, its own key as `ANTHROPIC_AUTH_TOKEN`, an empty `ANTHROPIC_API_KEY`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`, the pins and `REVERSEAPOC_EGRESS=1`. The env builder itself refuses an empty token.
- **preflight.** It refuses a hosted arm without `--allow-egress`, any `--allow-egress` naming another arm or an arm that sends nothing, and a missing, empty or blank key. The message names the variable and the endpoint, never the value.
- **driver.** `refuse_arms` runs first inside the drive lock, before the preflight's first command. It also covers the canary and refuses `--workers` above the arm's `max_workers`. `_Claim` carries its arm and builds its env through `session_env`, so Claude nights now also lose any inherited base URL and token (D-12). The init check passes a hosted arm's `accepted_init`. Records take `harness` and `backend` from the arm. A hosted `cost_usd` is `estimate_cost` with `cost_source: "estimate"`. `credit()` writes `MATCHED_BY`, `Matched-By: <model id>` and the arm's `Co-Authored-By` for non-Anthropic arms, in the night's match and in `--land-held` (`_held_arm` finds the arm from the record).
- **cli.** `--night-model ARM` is validated against the table. `--allow-egress ARM` is repeatable, and its refusals sit in `_harness_conflict`.
- **hooks.** `EGRESS_ENV = "REVERSEAPOC_EGRESS"`. With it set, the matching layer denies (naming D-10) any Read, Glob or Grep that can reach `orig/` or `third_party/` of this checkout or of a worktree in it. Every path form counts, and so do wildcard segments, extglob and other syntax fnmatch cannot model, `**` before a top level, slash-free Glob patterns from the top level, and any Grep from a top-level directory. Searches below `src/`, `include/` and the attempt directory stay allowed.
- **docs.** `docs/legal.md` gains "Model backends and what they receive", covering all seven backends, the 2026-11-09 opt-in, `sends_disassembly`, `--allow-egress`, the read denial, and keys by variable name with a link to toolchain.md. `docs/model-routing.md` gains "Backends" and "The local arm" (llama-server under `C:\llm\`, `--jinja`, `--alias`, one slot, its CPU competing with check compiles).

**5. [Rule 2 - Missing critical] Two security-review rounds on the egress rule (orchestrator, mid-plan)**

A plain segment naming either directory is refused at any depth, and wildcard segments are refused where a top level can sit. `**` before a top level, a Grep from a top level and any segment outside `[a-z0-9._*?-]` (judged as `**`) are refused as well. gitignore is not relied on.
- **Committed in:** baa56290, 21dbdf7f, 298fc50e, bdcdf107

**6. [Rule 2] A key pasted into `key_env` is never echoed**
- **Fix:** `_key_env` names the field without repeating the value. Test: `test_a_key_pasted_into_key_env_is_not_repeated`, added in Task 1's GREEN commit.
