# Phase 07.2 Plan 05: Region board Summary

**check records how many bytes differ in each 0x100 region of a function (counts only, summing to `bytes.differing`), and for a row of 256 B or more `attempt check` prints a board naming, per region, the saved plain check of this attempt that is exact or closest there**

## Accomplishments

- `check.compare_bytes` returns `regions`, one count per `BOARD_REGION_BYTES` (0x100) region from the row start. Each differing VA goes in its own region. A length difference is counted byte by byte from where the shorter side ends to where the longer side ends, with kept filler counted as ours, the same as `extra`. The tuple covers the longer side. `FunctionCheck.to_json` emits it as `bytes.regions`.
- The verdict is unchanged: `ok`, `differing` and `first_va` are computed exactly as before. `batch.py` and `gate.py` are untouched (`git diff --quiet main HEAD -- tools/reverseapoc/batch.py tools/reverseapoc/gate.py` exits 0).
- `attempt.region_board` reads this attempt's `checks.jsonl`. It keeps the lines whose `sweep` is false and whose source is `checks/NNNN.c`, then reads only `<attempt dir>/checks/NNNN.json` and picks the fewest differing bytes per region, with ties going to the earliest check. The run being summarised is passed in as `current`. Under 256 B it returns nothing.
- `_check_summary` prints the board right after the claimed function's window lines.
- `attempt.region_summary(fn)` returns `regions 0:0 1:3 2:12`, or None when the entry has no regions. 07.2-03 needs it for each observed note (D-02).

## Decisions Made

See `key-decisions` in the frontmatter. The main one: `region_board` takes a keyword-only `current`. `_record` writes `checks/NNNN.json` only after `_finish` has built the summary. Moving that write would change which JSON is saved when the summary raises, and the RULINGS give `_locked_check` to 03, so I left the save order alone and passed the run in as `current`.

## Deviations from Plan

**1. [Rule 3 - Blocking] `region_board` gained a keyword-only `current` parameter**
- **Found during:** Task 1
- **Issue:** the board runs inside the summary, before the wrapper saves the current check's JSON, so the fixed three-argument form could not see the run it was printing.
- **Fix:** added `current: tuple[int, Mapping] | None = None`, keyword-only. The positional contract `(attempt_dir, claim, size)` from RULINGS is unchanged, and a call with only those three arguments reads the saved checks alone.
- **Committed in:** 782d84dd, widened in 5e0d8b0f

**2. [Rule 2 - Missing critical] The board cannot turn a run into a tool error**
- **Found during:** Task 1
- **Issue:** the board's own reads (functions.csv, saved checks) can raise `AttemptError` or `FunctionsError` (both ValueErrors) or `OSError`. `_record` would turn that into a tool line and save the error record in place of the real check JSON.
- **Fix:** `_board` catches `OSError`/`ValueError` and prints `    region board: not shown (<reason>)` instead. The failure is reported, not swallowed.
- **Committed in:** 782d84dd, 5e0d8b0f

**Total deviations:** 2 auto-fixed (1 blocking, 1 missing critical). **Impact:** neither changes a verdict, and neither touches a file or function another plan owns.
