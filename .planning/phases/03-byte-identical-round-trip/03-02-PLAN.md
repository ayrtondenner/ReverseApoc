## Flagged assumptions

- D-15 says hash strings are never copied into test files, but tests/test_targets.py (Phase 2) already pins the manifest's md5 and sha1 values. That pin is the manifest's own regression test and doubles as a tamper lock: an agent that edits config/targets.toml to make the gate pass fails it. This plan reads D-15 as governing the round-trip tests and excludes tests/test_targets.py from the scan. If the owner wants D-15 applied to that file too, the pin would move to a hash-of-the-manifest check, which is a separate change.
