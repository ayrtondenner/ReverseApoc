## Sampling Rate

- **After every task commit:** the quick run plus the task's new test file.
- **After every plan:** the full host suite, then the container suite, one at a time, then the measurement gate.
- **Before `/gsd-verify-work`:** both suites must be green.
- **Max feedback latency:** a task waits only on its quick run and slices. The 974 s full suite is paid at plan close, never per task.
