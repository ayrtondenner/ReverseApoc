**ah/dh bytes (115 first refusals, the largest).** `Block_.get` of a high byte returns the full register's expression shifted
right by 8 and masked to a byte, sized 1. `Block_.set` of a high byte merges into the full register, keeping its other bytes.
`_full` folds `ah` into `eax`, so `_use_def` must count a high-byte write as a use and a def of the full register: treating it
as a plain def kills the low bytes' liveness. `SUB`'s size -1 entries stay the marker.

**Stack structs (47 + 33 first refusals, 22 static indexed rows).** A pre-pass over the row finds the slots whose address is
taken: `lea r, [esp + N]`, `mov r, esp`, and indexed `[esp + r*s + N]`. Each such slot becomes an array local, `char s_<N>[K]`,
