## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| tools -> `src/` and `include/` | Tools write under `build/` only; C lands through the gate | draft C, which is game-derived |
| tools and agents -> commits | Drafts, listings and evidence stay in gitignored paths | game-derived text and bytes |
| third-party code -> the host | Reused repositories are read, never run | unreviewed code |
| the skill and `attempt asm` -> matching sessions | What unattended agents read and may run | instructions, listings, notes |
| the owner's checkpoint -> the skill | A human stands between the results and the instructions | the curve, then the answer |
