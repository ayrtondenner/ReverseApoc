## Decisions Made

See `key-decisions` above. Two more, with their reasons:

- A hole clears the flags, so a jump after a hole is a hole too. A stale flag source would write a wrong condition silently.
- `measure_curve.py` retries on `dict(sigs)`. A strict lift that stops early reaches fewer callees than a hole lift, and `sigs` is order-sensitive, so a shared dict would let a retry change a later row's strict lift.

Found while building:

- `shl; sbb r1, r2; sar`, signed division by a power of two: 134 static uses, and `op: sbb` at 58 is the largest refusal. Daggerfall's lift.py has a branch for the idiom, which would need checking against `-4r`.
- x87 forms outside the plan's list: `fsqrt` 8, `fxch` 2, `fldln2` 2, `fldz` 2 first refusals, and `fld1` and `fyl2x` behind them. By uses, `fxch` is the largest at 66.
- A float value live across a block: `x87: stack live across a block end`, 5 rows. The stack would have to carry into a block's successors.
- A pending float load is not ordered against a later integer store: `flush` covers registers, not the float stack. At most 2 rows are affected, the only x87 rows that lift whole.
- A slot used both as a float and as an integer keeps its first type. It gives the 1 E1079, tacp 0x00064050, a hole draft with 29 holes.
- 13 rows hold a jump whose table sits inside a row `functions.csv` calls `game`: 14 jumps keep `jump: indirect`. Correcting those rows, or reading tables there, would clear them.
- A thunk's signature does not see its target, so a `jmp` thunk reads as void. With the high byte use rule this feeds `call: result of a void callee is used`, 10 rows.
- A high byte write as a use keeps the full register live, so a row can gain an invented argument. Splitting ah from eax in liveness would answer it, and D-03 does not ask for that.
- `reg: esp read before any write`: 17 first refusals, nearly all a mid-body `sub esp, N`. `Block_` restarts esp at each block.
- With an array low in the frame, every slot above it joins its span, so spills above a buffer read as `*(int *)(s_20 + 16)`.
- `setb`/`jb` after a result reads as `(unsigned)e < 0`, always false, where the carry is meant. Pre-existing for jumps.
- **For the review: `jcc` computes its condition before `end_assign_jump` assigns, so the draft applies the step twice.** Shown on a stub: `inc eax; jne L`, with L a merge, drafts as `r_eax = r_eax + 1; if ((r_eax + 1) != 0) goto L;`. That is a counted loop's shape, so it may cost real matches, though how many rows it reaches was not measured. It came over with the move, is outside D-03, and so is not fixed here. `switch` gets the order right.
- `mem: stack-relative` in `mem_addr` can no longer fire: read and write route esp to `slot`, and `lea` refuses first. Kept, as the plan says the test names esp.
- Lifter's `once`, `force_ret`, `narrow` and `array` parameters came over with the move, and no caller in `tools/` sets them. For the review's YAGNI lens.
- `import json` stays inside `result_used`, moved as it was.
