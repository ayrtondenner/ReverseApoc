## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Re-resolving isolation after forcing none | A plain `dispatch-isolation --plan X` call made after `--force-isolation none` overwrote the sentinel back to harness-worktree before a main-checkout dispatch | advisory | For a main-checkout plan, `dispatch-isolation --raw --phase 07 --plan 07-NN --force-isolation none` is the LAST call before the Agent dispatch |
| Doubled backslashes in Bash heredocs | The Bash tool halves `\\` in heredocs; a gate script regex broke | advisory | Write files with backslashes via the Write/Edit tools, not heredocs |
| Writing under build/ with Write/Edit | The project hook denies Write/Edit under build/ (D-16) | advisory | Use shell redirection for build/ files |
| Commits/suites on main while a main-checkout executor works | Concurrent writes or suites race on main and on build/test-cc | advisory | Merge worktrees and run gate suites only when no main-checkout executor is active (between checkpoints) |
| Leftover worktree after cleanup-wave | cleanup-wave can report blocked (not a working tree / remove failed / base_mismatch) though the merge happened | advisory | Verify with `git merge-base --is-ancestor <head> HEAD`, then remove the folder and `git branch -d`; a branch that merged main needs a manual `git merge --no-ff` |
