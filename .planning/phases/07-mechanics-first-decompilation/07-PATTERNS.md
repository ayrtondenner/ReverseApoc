### `tools/reverseapoc/callgraph.py` (utility, transform)

**Analog:** `tools/reverseapoc/contextpack.py` L517-541 (`CallIndex`). Reuse it for direct/tail edges; add typed `pointer`/`table`/`hand` edges beside it.

```python
class CallIndex:
    """Callees of every game/thunk row and the reverse map, from one pass over the LE."""
    callees: Mapping[int, tuple[int, ...]]
    callers: Mapping[int, tuple[int, ...]]

    @classmethod
    def build(cls, rows: Sequence[FunctionRow], flat: bytes | bytearray, fixups: Sequence[Fixup]
              ) -> CallIndex:
        starts = frozenset(row.start for row in rows)
        index = asm.FixupIndex(fixups)
        callees = {row.start: _row_callees(row, flat, index.overlapping(row.start, row.end), starts)
                   for row in rows if row.kind in _WALKED_KINDS}
        callers: defaultdict[int, set[int]] = defaultdict(set)
        ...
        return cls(callees, {va: tuple(sorted(found)) for va, found in callers.items()})
```
- Frozen dataclass, classmethod `build` from (rows, flat, fixups), sorted tuples for determinism. Keep `_WALKED_KINDS` semantics (runtime rows are leaves). Use `asm.FixupIndex` for fixup lookups; decoding through `reverseapoc.x86` (pinned capstone).

**TOML loader analog:** `tools/reverseapoc/targets.py` L123-138
```python
def load_manifest(path: Path | str | None = None) -> list[Target]:
    path = Path(path) if path is not None else DEFAULT_MANIFEST
    try:
        with path.open("rb") as fh:
            data = tomllib.load(fh)
    except (tomllib.TOMLDecodeError, UnicodeDecodeError) as exc:
        raise ManifestError(f"{path}: {exc}") from exc
    entries = data.get("targets")
    if not entries:
        raise ManifestError(f"{path}: no [[targets]] entries")
    if not isinstance(entries, list) or not all(isinstance(entry, dict) for entry in entries):
        raise ManifestError(f"{path}: 'targets' must be an array of tables ([[targets]])")
    return [_parse_target(i, entry) for i, entry in enumerate(entries)]
```

## Shared Patterns

### Atomic committed-data writes
**Source:** `tools/reverseapoc/fileio.py` L17-32 `write_atomic(path, data: bytes)` (random `.tmp` opened `"xb"`, `os.replace`). **Apply to:** members CSV, asm list, readlint-allow (if generated), cflags-proposals.toml, symbols.csv renames, status.csv, claims are the exception (O_EXCL create, `_O_NEW`).

### Error -> exit code convention
**Source:** cli.py `_cmd_check` (`except (*_ERRORS, CheckError)` -> `EXIT_TOOL` = 2) and `main` L1446-1455. **Apply to:** every new verb: 0 ok, 1 finding/violation, 2 tool/usage error. Module error class subclasses `ValueError`/`RuntimeError` like `ProgressError`, `DriverError`, `ManifestError`.

### Verb registration
