### `tools/reverseapoc/cli.py` (controller) - new verbs

**Analog:** `tools/reverseapoc/cli.py` itself.

Verb = `_cmd_<verb>(args) -> int` + `_add_<verb>_command(sub)` registered in `build_parser()` (l.415-466). Copy `_cmd_cc` / `_add_cc_command` (l.89-122):
```python
def _cmd_cc(args: argparse.Namespace) -> int:
    result = compile_source(args.src, args.obj, cflags=args.cflags, ...)
    if result.output.strip():
        # With --json, stdout stays one JSON document; the compiler's messages go to stderr.
        print(result.output.rstrip("\n"), file=sys.stderr if args.json else sys.stdout)
    if args.json:
        print(json.dumps(result.to_json(), indent=2))
    else:
        print(result.format())
    return 0 if result.ok else 1

def _add_cc_command(sub: argparse._SubParsersAction) -> None:
    default = "default: %(default)s"
    p = sub.add_parser("cc", help="...")
    p.add_argument("--json", action="store_true", help="print the result as JSON")
    p.set_defaults(func=_cmd_cc)
```
EXE selection: copy `_cmd_libmatch` l.141 `target = select_target(load_manifest(args.manifest), args.exe, args.manifest)`; protected-output refusal l.144 `refuse_output(output, args.orig, DEFAULT_ORIG, args.watcom_dir, DEFAULT_INSTALL)`; `--write` vs `--output` mutually exclusive group l.180-184.

Errors: each new module defines `class XxxError(ValueError)` and it is appended to `_ERRORS` (l.469-482); `main()` prints `reverseapoc {args.command}: error: {exc}` and returns 1. `check` needs exit code 2 for tool/usage errors (RESEARCH Pattern 11) - add that explicitly in `_cmd_check` rather than changing `main()`'s generic 1. Update the module docstring verb list (l.1-2).

### `tools/reverseapoc/functions.py` (model, CSV CRUD) - functions.csv / boundaries.csv / units.csv / symbols.csv

**Analog:** `tools/reverseapoc/libmatch.py` l.768-835 (runtime.csv).

Writer pattern (generated-by comment, fixed column tuple, `0x%08X` addresses, atomic write):
```python
def _cells(r: MatchRange) -> list[str]:
    return [f"0x{r.start:08X}", f"0x{r.end:08X}", r.segment, ...]

def format_runtime_csv(report, name) -> str:
    buf = io.StringIO()
    buf.write(RUNTIME_CSV_COMMENT.format(name=name) + "\n")
    writer = csv.writer(buf, lineterminator="\n")
    writer.writerow(RUNTIME_CSV_COLUMNS)
    writer.writerows(_cells(r) for r in sorted(report.ranges, key=_range_order))
    return buf.getvalue()

def write_runtime_csv(path, report, name) -> None:
    path = Path(path); path.parent.mkdir(parents=True, exist_ok=True)
    _write_atomic(path, format_runtime_csv(report, name).encode("utf-8"))
```
Reader pattern (skip `#` lines, exact header check, row-numbered errors):
```python
lines = [line for line in text.splitlines() if not line.startswith("#")]
reader = csv.DictReader(lines)
if tuple(reader.fieldnames or ()) != RUNTIME_CSV_COLUMNS:
    raise LibMatchError(f"{path}: header is not {','.join(RUNTIME_CSV_COLUMNS)}")
for number, row in enumerate(reader, start=1):
    try: rows.append(_parse_row(row))
    except (TypeError, ValueError) as exc:
        raise LibMatchError(f"{path}: data row {number}: {exc}") from exc
```
Path helper: copy `runtime_csv_path` (l.833) -> `config_dir(name) / "functions.csv"` using `targets.config_dir` (targets.py l.94-98). Columns per D-10: `start,end,name,kind,unit,evidence`; boundaries per D-08 (verdict `rule|ghidra|capstone|data-in-code` + reason); symbols per D-19 `address,name,kind`. Row type = `@dataclass(frozen=True)` like `MatchRange` (libmatch.py l.102). Seed from `read_runtime_csv` (l.813); runtime public offsets from LIB386 via `omf.Public.offset` (omf.py l.226-229), with a drift test.

### `tools/reverseapoc/omf2elf.py` + `tools/reverseapoc/elf.py` (transform)

**Analog:** `tools/reverseapoc/omf.py` (input model) - l.211-287:
```python
@dataclass(frozen=True)
class OMFFixup:
    offset: int  # segment-relative offset of the patched field
    size: int
    segment_relative: bool  # M bit: segment-relative, else self-relative
    location: int  # location type (9 = 32-bit offset)
    frame_method: int; target_method: int
    target_kind: str  # "segment", "group", "extern" or "frame"
    target_index: int; target_name: str
    displacement: int  # 0 when the record has none

@dataclass(frozen=True)
class Segment:  index, name, class_name, length, use32, data, fixups, unmaskable, backpatched
    is_code -> class_name.upper().endswith("CODE")
@dataclass(frozen=True)
class Module:   name, offset, segments, publics, externs, comdats, model, default_libraries, easy_omf, nbkpat_records
```
Constants style to copy for ELF (omf.py l.39-151): one named module constant per spec field with a trailing comment, e.g. `REC_FIXUPP = 0x9C  # fixups for the preceding data record`, `_REC_LEN = 1  # u16: body length plus the checksum byte`. `.claude/rules/tools.md` forbids bare binary-format offsets: write `EI_CLASS`, `SHT_REL`, `R_386_32 = 1`, `R_386_PC32 = 2`, etc. the same way. Error class `class OMFError(ValueError)` (l.191) -> `ElfError(ValueError)`.

Addend rule (RESEARCH Code Examples, TH GPLv3):
```python
stored = struct.unpack_from("<i", data, fx.offset)[0]
relative = not fx.segment_relative
struct.pack_into("<i", data, fx.offset, stored + fx.displacement - (4 if relative else 0))
rtype = R_386_PC32 if relative else R_386_32
```
Header line (first line of file): `# Derived from Theme Hospital decomp tools/omf2elf.py (GPLv3), https://github.com/matteo-pacini/theme-hospital-decomp`, followed by a module docstring, as le.py l.1-20 does for KKND.

`omf.py` modification: extend `_comdat` (l.674) to 0xC2 via `kind = rtype & ~_WIDE_BIT` (`_WIDE_BIT` l.103) and make `_nbkpat` (l.794) apply instead of only counting `nbkpat_records`. Tests in `tests/test_omf.py` with new builders in `tests/omfimage.py` (e.g. `comdat16`, `nbkpat`) following `record()`/`ledata32()` (omfimage.py l.16-72).

def _covered_fixups(fixups: list[Fixup], srcs: list[int], lo: int, hi: int) -> Iterator[Fixup]:
    """Fixups (sorted by src_va, with `srcs` their addresses) whose field overlaps [lo, hi)."""
    for fx in islice(fixups, bisect_left(srcs, lo - MAX_FIELD + 1), None):
