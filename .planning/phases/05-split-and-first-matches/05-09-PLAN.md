<objective>
Build the authoritative oracle of the pipeline: the KKND-style relocation check (SPL-09; built whatever the
spike's verdict, D-02) and the land step that turns a checked function into a spliced EXE with the original
link-time value kept at every relocated field on either side (SPL-10). `check` (plan 05-17) and `ninja verify`
share this one land step (Claude's discretion).

fields only, while our call fields are not LE fixups (research Pitfall 2). This plan closes both holes.

</objective>
