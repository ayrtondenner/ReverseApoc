### Candidate rules for a later plan (not changed here, as the plan says)

- **Shared exit** (2 rows, one per EXE): a Ghidra-only address whose only references are jumps from inside one function is not a start, as with case labels. The rule could decide it from the jump targets of the descent.
- **Calls from unreached code** (3 TACP rows): a Ghidra-only start that calls target, where the calls are decoded linearly in code the descent never reached. The rule could treat such calls as call evidence if the gap is first shown to be code (the TACP gaps decode with no undecodable byte and carry 114 and 385 LE fixups as instruction operands).
- **Reached from another function by jump or thunk** (UFO2P 0x000B7170, TACP 0x000D2019): a jump or thunk from a different row is start evidence.
