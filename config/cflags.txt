# config/cflags.txt -- which compiler, Watcom version and flags build each source (D-12).
# Read by `uv run reverseapoc cc SRC -o OBJ` (tools/reverseapoc/cflags.py).
#
# One rule per line, fields separated by whitespace:
#
#   <glob>  <compiler>@<version>  <flags...>
#
# - <glob> matches the source's repository-relative path with `/` separators (fnmatch,
#   case-sensitive; `*` also crosses `/`).
# - <compiler> is wcc386 or wpp386; <version> must be a version in config/watcom.toml.
# - The first rule must be the `*` default. A source takes the LAST rule that matches it, and a
#   source that no rule matches is refused.
# - `#` starts a comment, on its own line or after a rule.
#
# The wrapper owns these flags; they may not appear here in any case or spelling (Watcom ignores
# case and takes a value with or without `=`, so `-Iinc` is -i): -zq -zld -bt -fo -fr -fi -fh
# -ad -i. A flag is one option: it must start with `-` and hold no other `-` (Watcom starts a new
# option there), no `/`, no `\` and no whitespace.
#
# Evidence for the default: docs/toolchain.md, sections "Result" and "Flags" (Phase 4, measured
# per EXE; UFO2P and TACP give the same answer). 10.6 is the version consistent with both the
# codegen probe (10.5 byte-identical; 11.0 tied at -4r, a candidate until a Phase 5 match) and
# the linked 10.6 runtime library. The flags are the proven ones, written explicitly:
#   -4r   register convention (no 3S-only runtime row) and CPU target -4 (5-dword rep copies,
#         no unrolled 5-dword run)
#   -s    no stack checks: true for most code; the 40 (UFO2P) / 32 (TACP) functions that call
#         __CHK get per-glob rules without -s once Phase 5 maps them to files
#   -fpi  inline x87 with the emulator (an EMU387 row); wcc386's default, written out
# Candidates stay out until Phase 5 matches prove them (toolchain.md "Flags"): -o*, -zp*, -zm,
# -fp3/-fp5.

*  wcc386@10.6  -4r -s -fpi
