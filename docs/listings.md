# Listing drafts

Drafts of the third-party listings for ReverseApoc, one per section, each written in its target's own format.
**The owner sends every one of them by hand:** the owner opens each pull request and files the decomp.me issue.
Claude only drafts them here; it never opens, pushes, comments on or files anything on GitHub, decomp.me or any other
third party. decomp.me bans LLM and automated access, so no tool ever visits it: its draft is written from
[toolchain.md](toolchain.md) and the phase 6 context alone. The upstream formats of the three awesome-lists were read
with read-only `gh api repos/<owner>/<repo>/contents/<path>` calls on 2026-10-25; nothing was forked or written upstream.

Every draft follows the honest-listing rule in [legal.md](legal.md) (AI use, last bullet of "Community reception and
our conduct"): it says the project is AI-assisted (Claude Code), that every match is proven by byte comparison, that no
game files are distributed, and it links the repo and the progress page.

Facts the drafts rely on:

- Repo: <https://github.com/ayrtondenner/ReverseApoc>. Progress page (GitHub Pages):
  <https://ayrtondenner.github.io/ReverseApoc/>.
- Acceptance test: a function counts as matched only when objdiff reports 100% for it, an independent relocation check
  passes, and the rebuilt UFO2P.EXE and TACP.EXE are SHA-1 identical to the retail files.
- Compiler: Watcom C 10.6 (`wcc386`), default flags `-4r -s -fpi`; targets UFO2P.EXE (module `ufo24`) and TACP.EXE
  (module `tac4`), DOS/4GW LE executables.

Before sending any draft:

1. Pages is enabled and the progress page above loads (the pilot checkpoint sets the Pages source).
2. Re-read the target file upstream; if its layout changed since 2026-10-25, follow the current layout.
3. Send from the owner's own GitHub account, by hand.

PR body:

```md
Adds ReverseApoc to `categories/game-decompilation.md`, with the README regenerated by `scripts/build-readme.py`.

ReverseApoc is a byte-matching decompilation of X-COM: Apocalypse (MicroProse, 1997, DOS): readable C89 that,
compiled with the original Watcom C 10.6 compiler, rebuilds the two DOS/4GW LE executables (UFO2P.EXE and TACP.EXE)
byte for byte. It documents the original engine for the OpenApoc reimplementation and is not a port.

- AI use: the project is AI-assisted, openly. Claude Code writes the decompilation attempts; it never judges its own
  matches.
- Acceptance test: byte comparison. A function counts as matched only when objdiff reports 100% for it, an
  independent relocation check passes, and the rebuilt UFO2P.EXE and TACP.EXE are SHA-1 identical to the retail
  files. The agent is blocked from editing the original files, the hash manifests and the build scripts.
- No game files are distributed: no executables, assets, disassembly or compiler binaries are in the repository;
  users bring their own copy of the game and of the compiler.
- Repo: https://github.com/ayrtondenner/ReverseApoc
- Progress page: https://ayrtondenner.github.io/ReverseApoc/
```
